# ☁️ CloudStock — Inventario en la Nube

Proyecto de la asignatura **Computación en la Nube** — Unidad I.

## 🌐 Sitio publicado

**URL pública:** https://maxidxjejeclrak0-crypto.github.io/cloudstock/

## 📋 Descripción

CloudStock es una aplicación web estática de inventario que permite:

- Listar productos con nombre, cantidad y precio.
- Agregar nuevos productos con validación de datos.
- Eliminar productos del inventario.
- Filtrar productos por nombre en tiempo real.
- Ver estado del stock (⚠ bajo / ✔ OK).
- Calcular el valor total del inventario.
- Persistir datos localmente con `localStorage`.
